# Docker CLI vs Docker Desktop

What I Initially Thought:
Docker CLI and Docker Desktop were completely separate Docker environments.

What I Learned: 
They can interact with the same Docker Engine/daemon.

```text
Docker CLI ─────┐
                ├── Docker Engine
Docker Desktop ─┘
```

Therefore, containers created through the CLI can appear in Docker Desktop when both use the same Docker context/engine.

Useful Check
```text
docker context ls
docker ps -a
Key Point
```

Before assuming containers/images are "missing", check which Docker context/engine you're connected to.
