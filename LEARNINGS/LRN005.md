LRN-005 — Dockerfile vs Docker Compose
Dockerfile

Defines how the application image is built.

Base image
Dependencies
Application files
Startup command
Docker Compose

Defines how multiple services run together.

For example:

Application
    ↓
Redis
    ↓
Database
Key Point
Dockerfile
= Build the image


Compose
= Run/connect services

A Dockerfile can still be useful even when Docker Compose is used.
