# Docker Registry

### What I Initially Thought: 
A Docker registry is required so Docker CLI and Docker Desktop can share containers. But they both are the same thing just interfaces are different then what is the purpose of registry?

### What I Learned
A registry primarily stores and distributes container images. So its the library of images.

Examples:
```
Docker Hub
Amazon ECR
GitHub Container Registry
Private Registry
```

#### Typical workflow:

```
Developer
   ↓
docker build
   ↓
Image
   ↓
docker push
   ↓
Registry
   ↓
docker pull
   ↓
Server / Kubernetes
```


Key Point

Registry = image distribution
It is not a place where running containers live.
