# .dockerignore Problem

I initially included unnecessary project files in the Docker build context.

# Learning
Use .dockerignore to exclude files that don't belong in the image/build context.

Example:
```
.git
README.md
node_modules
*.log
.env
```

### Benefits
Smaller build context
Faster builds
Smaller images when unnecessary files would otherwise be copied
Reduced risk of accidentally including secrets

### Key Point
Only copy what the application actually needs.
